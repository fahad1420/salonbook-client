# SalonBook — Luxury Salon & Spa Frontend Web Application

High-end, bespoke appointment booking platform for **SalonBook**, designed with warm alabaster, deep espresso, and muted rose-gold accents.

## Tech Stack
- **Framework:** Next.js (App Router) with TypeScript (Strict Mode)
- **Styling:** Tailwind CSS with bespoke luxury editorial palette
- **Icons:** Lucide Icons
- **Notifications:** Sonner Toast Notifications
- **Deployment:** Vercel

## Core Application Modules
- **Public Showcase:** Hero banner, curated category navigation, 6+ live featured active services, and the Signature Experience standard.
- **Service Discovery:** Real-time search, category filters (supporting `?category=...`), and ascending/descending price sorting.
- **Protected Booking Workflow:** Service details, date picker, predefined time slot selection, conflict prevention validation, and immediate pending appointment reservation.
- **Customer Dashboard:** Reservation overview, status badges, view details modal, self-cancellation for pending bookings, Stripe checkout integration for confirmed bookings, and profile management.
- **Admin Command Center:** Operational metrics, service management with ImgBB upload only, appointment confirmation/cancellation, customer suspension toggles, and read-only financial ledger.
